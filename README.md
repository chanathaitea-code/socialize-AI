# SocialFlow AI — V0

Community manager autonome pour restaurants, food trucks et commerces.

**V0 : prototype cliquable** (données de démonstration Chana Thaï) — ouvrez `index.html` ou la version en ligne via GitHub Pages.

## Contenu
- `index.html` — prototype interactif : tableau de bord, calendrier, emplacements modifiables, story de la semaine, studio, design haute qualité, bibliothèque, validations, inbox, prospects et devis, analyse (vues, ventes/ROI), SEO & moteurs IA, paramètres.
- `docs/cahier-des-charges.md` — cahier des charges et architecture v1.1.
- `assets/parcours-client-socialflow.png` — le parcours client en une image.
- `assets/story-semaine-chana-thai.png` — maquette de la story hebdomadaire des emplacements.

## Feuille de route
Phase 0 : fondations Next.js + Supabase · Phase 1 : plannings et publication (pilote Chana Thaï) · Phase 2 : studio visuel + ventes caisse · Phase 3 : vidéo, inbox, prospects · Phase 4 : plateforme agence.
